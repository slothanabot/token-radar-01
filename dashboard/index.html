How the implied value is priced

No name is ever special-cased. Every row is priced from the snapshot's own figures by the same function, radar-2:

  1. Comparable multiple. For the protocol's category, the median market-cap-to-TVL ratio of the live-token protocols in that category. Thin categories shrink toward the global median (prior 5). Clamped to 0.02–1.50.
  2. Base = TVL × multiple.
  3. Growth = 1 + clamp(7d change, −60%, +120%) × 0.5.
  4. Maturity = 0.6 + min(age, 1095 days) ÷ 1095 × 0.4. Unknown age counts as 365 days.
  5. Breadth = 1 + 0.05 × extra chains, up to 1.20. More chains, wider distribution.
  6. Implied value = base × growth × maturity × breadth, rounded to whole dollars.

Token Radar (radar-2) ranks pre-token protocols by an implied value priced from live-token comparables — the median market-cap-to-TVL multiple of each category — then growth, maturity and chain breadth. A sortable, filterable dashboard with a detail view and a farm plan for every protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
